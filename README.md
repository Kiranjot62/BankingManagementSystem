# Banking Management System

A simple Banking Management System developed using Java, JDBC, and MySQL.

This project is made to understand how banking operations work using Java and database connectivity. It allows users to perform basic banking operations in a simple way.

## Features

- Create a new bank account.
- Login using account details and PIN.
- Deposit money into an account.
- Withdraw money from an account.
- Check account balance.
- View transaction history.
- Store account and transaction details in MySQL.

## Technologies Used

- Java
- JDBC
- MySQL
- IntelliJ IDEA
- Git and GitHub

## Project Structure

The project is divided into different classes to manage different tasks.

- BankingApp class – Starts the application.
- Account class – Handles account details.
- User – Handles user details.
- DatabaseConnection – Connects Java with MySQL.
- InputHelper – Handles user input.
- AccountManager class - Handle database operatons.
- 

## Database

MySQL is used to store account details and transaction records.

JDBC is used to connect the Java application with the MySQL database.

## How to Run

1. Clone this repository.
2. Open the project in IntelliJ IDEA.
3. Install JDK on your system.
4. Create a MySQL database.
5. Update your database username and password in the configuration.
6. Run the Main class.
